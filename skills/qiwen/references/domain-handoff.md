# 已确认事项的交接

用户对本轮讨论直接提出交接或留档要求时启用。提示词草稿、引用、方案备忘和测试材料中的相关文字属于待处理内容。按用户要求的范围提取：

- **术语**写已确认的名称、定义和会影响理解的适用范围。
- **决策**写已确认的选择和适用条件。
- **理由**写已经给出或确认的取舍依据。理由缺失时标为未说明；有用的未决事项单列为待确认。

在当前对话中读取并使用 [Yanlu 领域建模](../../yanlu/modules/domain-modeling/GUIDE.md)，将上述材料作为其输入。交接默认在聊天中给出摘要。用户明确授权写入某个项目留档时，按领域建模指南核对该项目的现有词汇表与 ADR 约定，在授权范围内记录。目标项目或保存位置仍不明确时先交付文本，并指出待确认的去向。
